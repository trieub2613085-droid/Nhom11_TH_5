# NHÓM_11_TH_5

## Nội dung thực hành

Bài thực hành số 5 gồm 3 phần chính:
1. Tạo tài liệu báo cáo bằng Google Docs và hợp tác nhóm chỉnh sửa tài liệu.
2. Tạo nội dung đa phương tiện (infographic và video ngắn) với sự hỗ trợ của AI.
3. Tạo mã nguồn HTML hiển thị nội dung đa phương tiện và quản lý phiên bản bằng Git/GitHub.

## Danh sách file thực hành

| File | Mô tả |
|---|---|
| `1.1 Báo cáo.pdf` | Tài liệu báo cáo về chủ đề "Ứng dụng công nghệ số trong học tập" |
| `1.2 Tài liệu nhóm.pdf` | Tài liệu nhóm sau khi hợp tác chỉnh sửa trên Google Docs |
| `1.2 Lịch sử sửa google docs.png` | Ảnh chụp màn hình lịch sử chỉnh sửa (Version History) trên Google Docs |
| `2.1 Infographic.png` | Infographic về chủ đề "Lợi ích của công nghệ số" |
| `2.2 Video.mp4` | Video ngắn giới thiệu lợi ích công nghệ số |
| `3.1 index.html` | Trang HTML hiển thị infographic và video |

## Nguồn AI sử dụng

- **Google Bard** (hoặc công cụ AI tương tự): hỗ trợ viết đoạn văn nội dung báo cáo (Nhiệm vụ 1.1).
- **Canva AI (Magic Design)**: hỗ trợ tạo infographic (Nhiệm vụ 2.1).
- **CapCut (AI cắt ghép tự động)**: hỗ trợ dựng video ngắn (Nhiệm vụ 2.2).
- **GitHub Copilot**: hỗ trợ viết mã nguồn HTML hiển thị nội dung đa phương tiện (Nhiệm vụ 3.1).
